10M particle strong scaling

The standard 10M Orion start (the 10M problem of all the recent tests), one maximum timestep, on one 128-core socket of mad11 (Intel Xeon 6756E, memory bound to that socket), one run at a time. Pure OpenMP: an OpenMP-only build, one process with N threads. Pure MPI: N ranks with one thread each. Code: thin-timers (all thin-substep changes, exact switches only: SINKONCE, INOSINKFAST, THINCUT). Hover or focus a point for its values.
