    How the phase times are estimated: ranks that finish a phase early wait at the next synchronisation point inside the timer of a later phase, so each rank's own phase times overstate the slow phases. Instead, taking the phases in code order, each phase is the slowest rank's time to the end of that phase minus the slowest rank's time to the end of the phase before. The phases then add up to the slowest rank's step exactly. “All other lines” are the remaining small timers.
